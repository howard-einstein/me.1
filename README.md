# me.1

A personal website for Howard Einstein — a place to share work, ideas, and projects.

## About

This site serves as a digital home for my portfolio, writing, and contact information. It is designed to be clean, fast, and easy to navigate, with a focus on presenting my work in a polished, professional way.

## Features

- Personal landing page
- Portfolio/project showcase
- About section and background
- Contact and social links
- Responsive design for desktop and mobile

## Tech Stack

This project is designed to be lightweight and easy to maintain. It can be built with modern static web technologies such as:

- HTML
- CSS
- JavaScript
- Optional: a static site generator or framework if needed later

## Local Development

To run the site locally:

```bash
git clone https://github.com/howard-einstein/me.1.git
cd me.1
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
